# 🌴 PalmCalc Pro

Aplikasi web kalkulator pemupukan kelapa sawit.

## Fitur
- ✅ Registrasi & Login akun
- ✅ Perhitungan kebutuhan pupuk (N, P, K, Mg)
- ✅ Estimasi biaya otomatis
- ✅ Riwayat perhitungan
- ✅ UI modern & responsif

## Cara Pakai
1. Buka `index.html` di browser
2. Daftar akun baru
3. Login dan mulai hitung

## Teknologi
HTML5 • CSS3 • Vanilla JavaScript • LocalStorage
